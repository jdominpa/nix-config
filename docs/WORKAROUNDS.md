# Workarounds

Temporary workarounds, pins and sandbox exceptions, each with the condition for
removing it.

## How to use

- **Adding:** the docs commit after the change adds a row with a concrete
  removal condition, the date and a revisit trigger.
- **Removing:** once the condition is met, revert the change, delete the row and
  mention the ID in the commit message.
- **Reviewing:** recheck the rows whose revisit trigger is due.

## Pins

None.
